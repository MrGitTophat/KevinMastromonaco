Mine maze

The goal of this project was to utlize all of the knowledeg that I gained during the first semester to create a functioning game within the console app.

From while loops, to functions, to console background color, we had to incorporate as many elements as possible and include a movement system that would allow for the cursor position to go up, down, left, or right. The main focus was to implement the movement system, get random element, and to change the dusplayed color of certain characters. I began to brainstorm several ideas, and went with something I thought would be interesting to make.

My idea for the Game Project was to make something similair to the randomly generating mines from Minesweeper, and make the player navigate around them to collect an object and get the highest score possible. I named my project Mine Maze, due to the nature of how the game was played.

To run the game, I utilized a switch statement between the intro screen and the game running.

Once the user presses enter, the game generates a random layout for the mines for the user to naviaget and colelct the green dollar signs. If the player losses any health, they can pick up the blue plus signs to get more health, as described in the intro screen.

After picking up a coin, a yellow circle would move randomly to "attack" the player.

Once the player runs out of lives, the game displays a Game Over screen with some stats.

What I learned

Overall, this project helped me solidify what I have learnt about programming and taught me how random generations worked, as well as how to get 2D collisions to function properly. Figuring out how randoms worked and that you could configure borders to a console app window was also very interesting.
