Menu system

The goal of this project was to explore how functions worked and to get the user to call a function from a list of options.

The user would input a number, which would then call a specific function by utilizing a switch. For example, if I were to type 1, it would call the rectangle function

From here, the program would prompt the user to give a number, then it would calculate and display the are of the rectangle.

It will continue to do this until the user inputs the number 6 or any number higher than that. This would result in the program displaying a thank you message, before ending.

What I learned

From this lab, I learned how to properly use a switch and how to properly implement function calls.
